# mine-translator
Minecraft names for blocks, items, entities, enchantments and potion effects in every language the game supports, taken from Mojang's official language files.

- `Languages/<code>.json`: one file per language. Each holds the `block.minecraft.*`, `item.minecraft.*`, `entity.minecraft.*`, `enchantment.minecraft.*` and `effect.minecraft.*` keys, plus `mine-translator.version`, the Minecraft version the file was built from.
- `Languages/version.json`: the Minecraft version of the current files and the list of languages.
- `language_names.txt`: every language code with its own name.
- `Configs/2.0/<code>/*.yml`: the ChatGames-Premium config files (messages, menus, word lists, trivia, comments...) translated into each language, for config format 2.0. `Configs/2.0/version.json` lists the languages, the Minecraft `lang` codes each one covers and a version per language; the plugin downloads a language when a server's `lang` asks for it or its version goes up.

Files are only ever added to: a name from an older Minecraft version stays when Mojang drops or renames it, so plugins and servers on older versions keep finding the keys they use.

The files are generated by `scripts/build-translations.py` in ChatGames-Premium.

The config files are built by `scripts/config-translations.py` in ChatGames-Premium from the translations in its `translations/configs/` folder, which also explains how to add a language. Languages so far: English, Español, Français, Português, Deutsch, Italiano, Nederlands, Polski, Русский, Türkçe.
